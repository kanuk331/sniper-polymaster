# Фаза 1: walk-forward копирования — результаты

*Дата: 2026-11-06. Код: `src/sniper/` (ветка `hoplite/leontinoi-8866bb9a`). Сырые отчёты: `reports/` (не в git).*

## Вывод

1. **Копировать по одной статистике навыка нельзя.** На вневыборочном периоде (01.09–16.10.2026) все группы,
   кроме одного кошелька, после комиссий и спреда дают копировщику убыток, и он растёт с задержкой.
2. **Единственный прибыльный кандидат — некопируемый архетип.** makeit99 покупает в секунды после публикации
   макро-данных (Bank of Israel, ISM PMI, JOLTS). Его «прибыль копировщика» почти наверняка артефакт модели цены
   (раздел 4). Без него 4 других кандидата дают +1.2% при задержке 10 с и −4% … −16% при 60–900 с.
3. **Скоринг слабо, но в правильную сторону ранжирует кошельки.** Spearman(θ̃ до среза, ROI копировщика после)
   = +0.08 … +0.14 на ~200 кошельках; значимость пограничная (p ≈ 0.05 только при 300–900 с).
4. Это совпадает с литературой (доля «умелых» ~3%, живой тест копирования убыточен). Итог фазы 1 — не готовый
   список «кого копировать», а инструмент, который честно показывает, что копируемого преимущества пока не найдено,
   и фильтрует 96% кошельков как некопируемые.

## 1. Постановка

| Параметр | Значение |
|---|---|

| Данные | `/v2/activity` с 01.01.2026, ≤20 000 строк на кошелёк → 16.0 млн строк; 698k токенов и 534k рынков (резолюции, события, комиссии) |

| Оценка | сигналы 01.09–16.10.2026 (45 дней); исходы известны на 06.11; нерезолвнутые позиции (~10% стоимости) оценены по себестоимости |
| Копировщик | $100 на ордер лидера; цена = max(цена CLOB через задержку + 1¢, худший уровень ордера лидера); пропуск, если цена выше VWAP лидера на 1.5¢ и больше или вне [0.03, 0.97]; комиссия тейкера по категории; выходы пропорциональны продажам и merge лидера |

## 3. Результат копирования (v3)

ROI копировщика против бенчмарка лидера (те же сигналы по цене лидера без комиссий):

| Тир | Задержка | Кошельков | Ордеров скопировано | ROI копировщика | ROI лидера | Доля кошельков в плюсе |
|---|---|---|---|---|---|---|
| candidate | 10 с | 5 | 601 | **+13.3%** | +20.0% | 0.8 |
| candidate | 60 с | 5 | 566 | **+24.0%** | +33.1% | 0.4 |
| candidate | 300 с | 5 | 553 | **+13.3%** | +22.7% | 0.6 |
| candidate | 900 с | 5 | 530 | **−4.4%** | +9.3% | 0.4 |
| → без makeit99 | 10 / 60 / 300 / 900 с | 4 | — | **+1.2% / −4.0% / −11.4% / −16.3%** | — | — |
| noise | 10 / 60 / 300 / 900 с | 121 | ~14k | −5.2% / −5.4% / −7.7% / −10.6% | +0.1% … −4.4% | 0.28–0.35 |
| insufficient | 10 / 60 / 300 / 900 с | 150 | ~8k | −3.6% / −6.8% / −12.9% / −19.6% | +5.4% … −8.6% | 0.14–0.28 |
| excluded | 10 / 60 / 300 / 900 с | 150 | ~3.5k | −11.4% / −13.7% / −24.3% / −32.0% | −6.3% … −24.5% | 0.33–0.43 |

Что видно:
- **Издержки копировщика ≈ 5 п.п.** даже при 10 с: у noise лидер ≈ 0%, копировщик −5%. Это комиссия, спред
  и упущенные сигналы: при 10–60 с пропускается 31–51% сигналов (из них 18–40% из-за ухода цены, остальное — экстремальные цены).
- **Задержка дорогая:** каждая ступень 10 → 60 → 300 → 900 с ухудшает ROI во всех группах.
- **Отсев архетипов работает:** excluded — худшая группа и у лидеров, и у копировщиков.

## 4. Найденные и исправленные ошибки бэктеста

Каждая из трёх версий завышала результат; цифры v1 и v2 недействительны.

| Версия | Проблема | Исправление |
|---|---|---|
| v1 | τ² методом моментов = 0, у всех кошельков одинаковое θ̃ | τ² по DerSimonian–Laird |
| v1 → v2 | копировщик «покупал» по устаревшей минутной цене CLOB сразу после того, как лидер выкупил ликвидность | цена копировщика не лучше цены лидера |
| v2 → v3 | ордер лидера, пробивший стакан (много филлов по растущим ценам), копировался пофилльно | сигнал = ордер (tx, токен, сторона); цена не ниже худшего уровня |

Оставшееся ограничение: истории стакана нет, поэтому глубина и влияние на цену не моделируются. Для makeit99
(покупки после публикации данных в тонких рынках) это ключевое: его +$15k в симуляции нельзя считать реальными,
пока сигнал не проверен на живом стакане в paper-режиме.

## 5. Ограничения

- **Один срез и один горизонт.** Нужен rolling walk-forward (ежемесячно) и бутстрэп по событиям для доверительных
  интервалов ROI копировщика.
- **Мало кандидатов (5).** Различие candidate против остальных статистически не установлено.
- Категория `unknown` у большинства кандидатов: у части рынков Gamma не отдаёт `feeType` (вероятно, рынки без комиссий).
- Ставка 1 ордер = $100 без учёта размера ордера лидера и без риск-лимитов (Kelly и лимиты — в фазе 2).
- 2% токенов и <1% рынков не обогатились; их ставки не участвуют в скоринге.

## 6. Что это значит для продукта

1. **Paper trading обязателен** перед любыми деньгами. Бэктест без стакана систематически оптимистичен; ловить это
   должен live-режим со снимком стакана (`/book`) в момент сигнала.
2. **Новый фильтр «некопируемо по скорости»:** доля сигналов, где цена ушла за потолок за 10–60 с (у makeit99 ≈57% при 60 с,
   у noise ≈27%). Его можно считать в скоринге по истории цен.
3. **Фокус на долгих позициях.** Издержки копировщика (~5 п.п.) окупаются только при большом edge на ставку,
   то есть в долгих событийных рынках, а не в спорте и быстрых рынках.
4. **Метрика продвижения кошелька** — положительный ROI копировщика на rolling walk-forward, а не статистика навыка.

## Воспроизведение

```bash
export SNIPER_DB_PATH=data/live.sqlite
uv run sniper universe markets --snapshot wf-2026-09 --end-min 2026-03-01T00:00:00Z --end-max 2026-08-25T00:00:00Z \
    --markets 150 --trades-per-market 3000 --min-notional 5000
uv run sniper backfill --snapshot wf-2026-09 --since 2026-01-01 --max-items 20000 --concurrency 6   # ~40 мин
SNIPER_RATE_LIMIT_SHARE=0.7 uv run sniper enrich                                                   # ~16 мин
uv run sniper backtest --snapshot wf-2026-09 --split 2026-09-01 --gap-days 7 --horizon-days 45 \
    --latencies 10,60,300,900 --sample-noise 150 --sample-excluded 150 --out reports/wf-2026-09-v3.json  # ~10 мин
```
