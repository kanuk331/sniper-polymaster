## 2026-11-06 — фаза 1: бэктест копирования и walk-forward
- `backtest.py`: симуляция копировщика. Для каждой BUY-сделки лидера в окне: цена CLOB через `latency_s` + полуспред,
  комиссия тейкера C·rate·p(1−p) по категории рынка, пропуск при уходе цены больше `max_premium` от цены лидера,
  пропуск экстремальных цен (<0.03, >0.97). Выходы пропорционально повторяют SELL и MERGE лидера, доля выхода считается
  по его реальным холдингам за всю историю. Остаток держится до резолюции, нерезолвнутые позиции оцениваются по себестоимости.
  Бенчмарк лидера — те же сигналы по его ценам без комиссий; `copy_efficiency` = PnL копировщика / PnL бенчмарка.
- Walk-forward: скоринг по данным до `split − gap`, симуляция на `[split, split + horizon)`; в симуляцию идут все
  candidate и watch плюс выборки noise, insufficient и excluded как контрольные группы. Spearman θ̃ против ROI копировщика.
- CLOB `/prices-history?fidelity=1`: окно до 7 дней работает (168 ч → 10 054 точки с шагом 60 с), 30 дней даёт
  HTTP 400 «interval is too long» → окна ограничены 3 днями.
- CLI: `sniper backtest --split ... --latencies 10,60,300,900`.

## 2026-11-06 — первый живой walk-forward (v1) и две найденные проблемы
- Срез 2026-09-01, gap 7 дней, горизонт 45 дней, задержки 10/60/300/900 с. Скоринг 3032 кошельков:
  candidate 5, watch 1, noise 121, insufficient 163, excluded 2742. В симуляции 427 кошельков, 34 483 окна цен.
- v1 показал у candidate ROI копировщика +14…+25%, но разбор выявил две проблемы, поэтому v1 **недействителен**:
  1. EB-shrinkage схлопнулся: у всех θ̃ = 0.0396, потому что τ² по методу моментов = 0 (его забивают кошельки
     с огромным SE). Исправление: τ² по DerSimonian–Laird.
  2. Плюс candidate держался на одном кошельке (makeit99: +$15.4k из +$14.1k суммарно). Он покупает
     в первые секунды после публикации макро-данных (Bank of Israel, ISM, JOLTS), и цена за минуту уходит с 0.6
     до 0.995. Копировщик «исполнялся» по ещё не обновлённой минутной цене CLOB, то есть по ликвидности, которую
     лидер уже выбрал. Исправление: копировщик входит не дешевле и выходит не дороже цены лидера.
- Бэктест v2 перезапущен с исправлениями (цены из кэша).

## 2026-11-06 — walk-forward v2 и третья проблема: «пробой стакана»

  при задержке 10/60/300/900 с: ROI +0.8% / −4.4% / −11.7% / −16.7%.

  не ниже худшего уровня при покупке и не выше худшего уровня при продаже; потолок премии считается от VWAP.
  Тест `test_book_sweep_is_one_signal_priced_at_worst_level`. Запущен v3.
